# Mouse mover 

A simple python script that moves your cursor continuously to prevent inactivity.

## Prerequisites 
Python 3+

## Installation

Install the required libraries:

```bash
pip install pyautogui keyboard
```

Clone the repo locally:

```bash
git clone https://github.com/TheBlueStickman/Mouse-mover.git
```

Navigate to the project directory:
```bash
python mouse_mover.py
```

To end the program press ESC.

## Configuration
To change the amount of time the cursor waits at each point, 
change the "seconds" variable on line 5.
